# Projetos Python

Repositório com alguns dos projetos que desenvolvi durante meus estudos de Python.

Aqui estão projetos feitos para praticar lógica de programação, estruturas de dados, funções, programação orientada a objetos e criação de pequenos sistemas.

## Projetos

### Bomba Relógio

Um jogo simples desenvolvido em Python.

O jogador precisa descobrir uma senha de 4 números antes que o tempo acabe. O jogo possui número limitado de tentativas e fornece algumas dicas durante as tentativas.

**Conceitos praticados:** Variáveis, tipos de dados, estruturas condicionais, laços de repetição, funções, números aleatórios e entrada e saída de dados.

### Sistema de Estoque

Sistema desenvolvido para praticar a criação de um sistema de gerenciamento de produtos.

É possível cadastrar produtos e trabalhar com informações relacionadas ao estoque.

**Conceitos praticados:** Programação Orientada a Objetos, classes, objetos, métodos, listas, dicionários e organização de código.

### Sistema de Cálculo de Salários

Programa desenvolvido em Python para realizar cálculos relacionados a salários.

O projeto foi criado como uma forma de praticar operações, condições e organização da lógica do programa.

**Conceitos praticados:** Variáveis, operações matemáticas, estruturas condicionais, funções e entrada e saída de dados.
